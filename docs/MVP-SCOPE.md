# MVP 需求冻结

以用户 2026-11-11 指令为准。

1. 小红书博主主页：已加载笔记真实采集、滚动增量去重、图文视频识别、爆款筛选、赛道定位和可模仿性分析。
2. 小红书单篇：图文与视频基础分析、标题正文拆解、优化建议；不能声称分析未读取的视频。
3. AI 创作：原创标题正文、封面配图、视频脚本，实际调用提供商。
4. 小红书转公众号：大纲、扩写、标题、摘要、正文、HTML/Markdown 导出。
5. 公众号转小红书：主题拆解、多个不同角度选题、标题正文和图片。
6. BYOK：用户配置密钥并真实调用模型。
7. SaaS：Workers + D1 基础，为后续会员、积分、订阅预留接口。
8. 必要本地保存：研究报告、分析和创作结果的搜索、删除、导出。
9. 后续新增：从已打开的 X 帖子提取可见正文，或粘贴原文，改写为中文微信公众号文章，保留已采集的原帖链接并支持保存和导出。
10. 本地一键图文改写：在当前打开的 X 或小红书帖上，用已保存的 BYOK 模型生成跨平台通用稿，并在浏览器内保存稿件、来源与原帖图片链接。稿件可编辑、复制和导出，供之后发布。

技术：pnpm workspace、WXT、React、严格 TypeScript、Chrome MV3；本地优先，云端可选。解析与 UI 分离。未来平台通过 Adapter 扩展。

复杂素材知识库、研究项目系统及 X 以外的海外平台解析器仍按原冻结范围处理。X 热帖由用户选定。业务验收以真实环境结果为准。
