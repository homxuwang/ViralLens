# ViralLens 实施计划

## 当前范围

按照总指令，先完成 Phase 0：确认空目录和开发环境，拆分可验证的交付阶段。产品采用 Chrome Manifest V3、WXT、React、TypeScript、pnpm monorepo；本地数据优先，云端能力可选。首批平台仅小红书和微信公众号。

## 阶段与验收

1. **Phase 1：可安装扩展骨架。** 建立 monorepo、WXT Side Panel、内容脚本、后台通信、基本路由和设置。验收：构建产物可由 Chrome 加载，面板能识别当前标签页并显示真实状态。
2. **Phase 2：页面提取与本地库。** 建立统一提取器接口、数据模型、Zod 校验、Dexie 存储；实现小红书博主主页和单篇笔记、微信公众号文章的可见内容提取。验收：在真实页面采集、去重、标记缺失字段并保存；用户滚动后可续采。
3. **Phase 3：研究与分析。** 基于真实样本统计互动数据、分别分析图文与视频；接入 BYOK 文本模型，生成有样本数和证据引用的研究报告与单篇分析。验收：完整走通工作流 A、B 的文本部分。
4. **Phase 4：创作与跨平台。** 实现原创改写、双向转换、视频脚本、图片模型接入、编辑保存和 Markdown/HTML/TXT 导出。验收：工作流 B、C、D、E；缺少外部 API 配置时明确显示不可用。
5. **Phase 5：可选云端与交付。** Cloudflare Worker、D1 基础接口，为后续会员、积分、订阅预留接口；测试、构建、文档与安装验收。当前不实施真实支付或云同步，新增功能须经确认。

每阶段运行类型检查、lint、相关测试与构建，并更新 `docs/PROGRESS.md`。

## 主要风险与处理

- **平台 DOM 变化与访问限制：** 提取器按平台隔离，使用多候选选择器和结构化失败原因；只处理用户已打开且加载的内容，不绕过登录或反爬。
- **样本偏差：** 报告记录已采集数量、覆盖范围、字段缺失及置信度；不声称覆盖博主全部历史内容。
- **AI 事实错误与版权：** 提示词要求证据和推断分离，不编造数字、案例；创作结果须为原创表达，用户确认内容使用权。
- **密钥与费用：** BYOK 密钥留在本地配置，模型调用有超时和错误处理；SaaS 密钥仅存服务端，额度由服务端核算。
- **外部服务依赖：** AI 和图片生成需要用户配置有效提供商；Mock 仅用于测试并在界面标明。
