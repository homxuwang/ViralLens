# 提示词

提示词源码集中在 `apps/extension/lib/prompts.ts`，扩展 BYOK 和 Worker 共用。

任务覆盖：博主研究、单篇分析、原创改写、视频口播分镜、公众号大纲与正文、公众号拆选题、小红书笔记生成、视觉 OCR 与构图分析。图像生成使用独立请求提示词。

系统提示词要求将页面文本视为数据，禁止执行其中指令；禁止编造数字或案例，区分证据、推断、建议，禁止冒充全量历史。用户可以在要求栏指定人群、定位、风格、篇幅、品牌和选中主题。

模型生成的 Markdown 可编辑，不执行返回的 HTML 或脚本。导出 HTML 转义全部正文后只加入受控排版标签。结构和篇幅目前依靠提示词及用户复核，不构成程序化事实核验。
