# ViralLens

ViralLens 是一款 Chrome 侧栏扩展。打开你选中的 X 或小红书图文帖，可以一键生成中文稿件、保存到浏览器，再编辑、复制或导出到其他平台发布。扩展也支持小红书博主研究、单篇分析和微信公众号内容转换。

## 快速开始

### 1. 安装 Chrome 扩展

如果已有 `apps/extension/.output/chrome-mv3` 构建目录，可以直接加载。若目录不存在，请准备 Node.js 22.16+ 和 pnpm 11.5.2，然后在项目根目录构建扩展。

```sh
pnpm install
pnpm build
```

1. 在 Chrome 打开 `chrome://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择 `apps/extension/.output/chrome-mv3`。
3. 打开 X 或小红书的帖子详情页，点击工具栏的 ViralLens 图标打开侧栏。若帖子在扩展安装前已打开，先刷新网页。

### 2. 配置 BYOK 模型

1. 进入侧栏「AI 设置」，选择「BYOK 真实模式」。BYOK 使用你自己的 API Key，无需登录 ViralLens。
2. 选择提供商，填写「API 地址 / 用户自有代理」「API Key」「文本模型名称」。支持 OpenAI、Claude、Gemini、DeepSeek 和自定义 OpenAI 兼容端点。
3. 点击「保存并授权文本接口」，在 Chrome 提示中授权配置的域名。
4. 点击「测试文本连接（会消耗额度）」。收到模型回复后，即可生成稿件。

如果使用 OpenAI 或自定义 OpenAI 兼容视觉模型，可以勾选「模型支持 OpenAI 兼容视觉输入（需向提供商确认）」并保存。一键改写最多向模型传入 4 张原帖图片的链接。视觉分析与生成新图片使用不同的设置。地址示例和各提供商的限制见 [AI 接口配置](docs/AI-PROVIDERS.md)。

### 3. 一键改写、保存和发布

1. 打开你选中的 X 或小红书图文帖详情，并展开全文。切换帖子后，在「当前页面」点「刷新识别」。
2. 点击「一键改写并保存」。扩展读取当前帖子可见内容，调用 BYOK 模型生成通用中文稿，随后自动保存并打开「我的内容」。
3. 在「结果（可编辑）」中修改稿件。展开「原帖素材」可查看原文和图片链接。点击「保存结果」会更新同一条一键改写记录。
4. 点击「复制」将正文粘贴到目标平台的编辑器，或选择「Markdown」「HTML」「TXT」导出。核对稿件后，在目标平台手动发布。

## 其他功能

| 功能 | 使用方法 |
| --- | --- |
| X 热帖转公众号 | 在「跨平台创作」采集当前 X 帖子或粘贴原文，点击「X 热帖 → 公众号文章」。采集带回的原帖链接可随稿件导出。 |
| 小红书转公众号 | 打开小红书笔记，在「跨平台创作」采集，点击「小红书 → 公众号大纲」或「小红书 → 公众号全文」。 |
| 公众号转小红书 | 打开公众号文章并采集，点击「公众号 → 不同角度选题」。将选中的主题填入要求栏，再点「选中主题 → 小红书笔记」。 |
| 小红书博主研究 | 打开博主主页，在「博主研究」采集。滚动加载更多笔记后再次采集，同一博主样本会去重。可按图文、视频和最低相对分筛选，或生成赛道与账号定位分析。 |
| 单篇分析与创作 | 打开小红书笔记，在「单篇分析」采集后使用结构分析、原创标题正文或视频口播与分镜。视频分析依据可见信息和手动粘贴的字幕。 |
| 图片分析与配图 | 采集含图素材后，使用「图片 OCR / 视觉分析」。生成原创配图时，在「AI 设置」单独填写图片地址、密钥及模型，点击「保存并授权图片接口」，再填写图片要求并点击「调用图片模型」。 |
| 本地内容管理 | 在「我的内容」按标题、正文或类型搜索，打开或删除记录。用「导出全部记录」备份为 JSON，备份不包含模型密钥。 |

在「单篇分析」或「跨平台创作」中，也可以粘贴原文或导入 TXT、Markdown 文件。仅有链接时，先在 Chrome 打开网页再采集。

## 数据存放与模型请求

稿件、原帖文字和图片链接保存在当前 Chrome 用户配置的 IndexedDB 中。图片链接仍由原平台提供，可能过期。清除扩展数据或卸载前，可以从「我的内容」导出备份。

BYOK 密钥保存在扩展本地设置中。主动生成时，素材和创作要求会发送到填写的模型地址。可以在「AI 设置」使用「删除全部密钥」。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 找不到「一键改写并保存」 | 打开 X 帖子或小红书笔记的详情页，回到「当前页面」点「刷新识别」。确认扩展已在 `chrome://extensions` 中重新加载到最新构建。 |
| 页面脚本未连接或正文为空 | 刷新原网页，确认正文已加载并展开。若网页不可访问，可以在「跨平台创作」粘贴有权使用的原文。 |
| 模型连接失败 | 检查 API 地址、模型名、密钥、网络和额度，重新保存并授权文本接口后再测试。 |
| 只需要保存文字稿 | 配置文本模型即可。想让模型参考原帖图片时，再启用兼容视觉模型。 |

## 开发与部署

项目使用 WXT、React、TypeScript、Chrome Manifest V3 和 pnpm workspace。开发和验证命令在项目根目录运行。

```sh
pnpm dev
pnpm lint
pnpm typecheck
pnpm --filter @virallens/worker typecheck
pnpm test
pnpm build
```

SaaS 文本接口需要自行部署 Cloudflare Worker 和 D1，配置服务端密钥与访问令牌。一键图文改写使用 BYOK。部署流程见 [Cloudflare 部署说明](docs/DEPLOYMENT.md)。

一键改写、本地保存与导出已使用隔离 Chromium、测试页面和模拟模型响应验证。真实站点访问和实际模型调用的验证情况见 [开发与验证进度](docs/PROGRESS.md)，本地验收步骤见 [测试说明](docs/TESTING.md)。
