# 检查与最终验收

`pnpm test`：页面分类、防伪造域名、DOM 提取、计数、缺失值、去重、分组排序、HTML 转义和各提供商请求协议。AI 测试使用模拟 HTTP 响应，不构成真实模型调用验收。

`pnpm typecheck` 检查扩展；`pnpm --filter @virallens/worker typecheck` 检查 Worker；`pnpm lint` 检查 apps；`pnpm build` 构建扩展。

最终验收需真实浏览器、平台访问、用户模型密钥和可选 Cloudflare 部署：

1. 博主页先采集、滚动再采集，核对样本数量、去重、类型与指标；执行研究并核对证据。
2. 图文/视频详情提取，运行分析、原创标题正文、视频脚本和图片生成；保存并重新加载验证持久化。
3. 小红书生成公众号大纲和全文，编辑并导出 HTML/Markdown/TXT，核对事实和篇幅。
4. 公众号提取，生成不同角度选题，选择主题后生成笔记和图片。
5. 无 SaaS 登录时通过 BYOK 完成全链路；错误密钥、额度不足、超时要显示失败。
6. 内容库搜索、打开、删除和备份；删除密钥后关闭重开验证。
7. 部署 Worker/D1，验证未授权 401、余额不足 429、成功扣额、失败退款和客户端不能改额。
8. 打开一个可见正文的 X 帖子，执行 X → 公众号。核对采集的是当前主帖，导出的 HTML 与 Markdown 包含原帖链接。再切换到小红书博主主页采集，核对样本只来自当前博主。

2026-11-24 复验使用独立的 Chromium 配置加载实际构建。使用测试 HTML 和模拟模型 HTTP 响应跑通面板页面、页面通信、X 改写与导出、小红书博主增量去重和样本隔离、小红书单篇分析与创作、图片返回、公众号互转、本地保存、搜索、备份、删除及密钥删除。工具栏打开侧栏的配置已核对，原生弹出交互未手动测试。

Worker 请求处理器使用本地 SQLite 执行真实迁移和 SQL，并通过模拟模型响应检查令牌认证、X 改写任务、扣额、失败返还和零余额。云端 D1 和真实模型端到端检查仍待有可用配置后执行。真实网页访问探测的结果见 `PROGRESS.md`。
